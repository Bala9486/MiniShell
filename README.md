# Mini Shell Implementation in C

## Project Overview

Developed a Mini Shell application using C programming in Linux. The project replicates basic Linux shell functionalities by accepting user commands and executing them through system calls.

## Technologies Used

* Programming Language: C
* Operating System: Linux (Ubuntu)
* System Calls: fork(), exec(), wait(), getpid()
* Tools: GCC, Linux Terminal

## Features

* Command-Line Interface
* Command Execution
* Internal Command Handling
* External Command Execution
* Process Creation and Management
* Signal Handling
* Pipeline Implementation

## Concepts Learned

* Process Management
* System Calls
* Process Creation using fork()
* Program Execution using exec()
* Inter-Process Communication
* Signal Handling
* Linux Command Execution

## Compilation

```bash
gcc *.c -o minishell
```

## Execution

```bash
./minishell
```
